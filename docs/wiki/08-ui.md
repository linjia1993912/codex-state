# 08 · UI 视图

> 文件：
> - `Sources/CodexStateCore/UI/NotchRootView.swift`
> - `Sources/CodexStateCore/UI/PeekUsageView.swift`
> - `Sources/CodexStateCore/UI/ExpandedUsageView.swift`
> - `Sources/CodexStateCore/UI/DailyTrendView.swift`

UI 层全部基于 SwiftUI，运行在 `@MainActor`。视图只读取 `UsageStore.snapshot` 与 `NotchPresentation`，不直接 IO。

## 1. `NotchRootView`

```swift
@MainActor
public struct NotchRootView: View {
    @Bindable private var store: UsageStore
    @Binding private var presentation: NotchPresentation
    @Environment(\.accessibilityReduceMotion) private var reduceMotion
    @State private var hoverTask: Task<Void, Never>?
}
```

### 1.1 三态切换

- `.collapsed`：纯黑胶囊 `150×30`，仅暴露 `accessibilityLabel = "Codex 用量"`。
- `.peek`：`PeekUsageView`，点击进入 `.expanded`。
- `.expanded`：`ExpandedUsageView`，自带关闭按钮。

### 1.2 悬停调度

```swift
.onHover { hovering in
    switch (presentation, hovering) {
    case (.collapsed, true): schedule(.peek, after: .milliseconds(120))
    case (.peek, false): schedule(.collapsed, after: .milliseconds(250))
    default: hoverTask?.cancel()
    }
}
```

- 入屏 120ms 延迟展开，避免误触。
- 离屏 250ms 延迟收起，避免快速移动到内容区时闪退。
- `Task` 持有延迟任务；切换/消失时立即取消。

### 1.3 减少动态效果

- 监听 `@Environment(\.accessibilityReduceMotion)`。
- 切换 `presentation` 时若开启减少动态效果，直接赋值；否则使用 `withAnimation(.easeInOut(duration: 0.18))`。
- `.animation(reduceMotion ? nil : .easeInOut(duration: 0.18), value: presentation)` 与平台层 `reposition(animated:)` 保持一致。

### 1.4 尺寸

外层 `.frame(width:height:)` 显式绑定到 `NotchPanelController.size(for: presentation)`，避免动画期间布局漂移。

## 2. `PeekUsageView`

```swift
struct PeekUsageView: View {
    let snapshot: UsageSnapshot
}
```

- 顶部 32pt 透明区域作为"连接带"，与物理刘海融合；指标从其下方布局。
- `HStack` 渲染 `NotchLayoutPolicy.metrics(...)` 提供的 1~2 个 `PeekMetric`。
- 每个指标包括标题、数值、可选的 `ProgressView`（`progress == nil` 时隐藏）。
- `accessibilityElement(children: .combine)` 让 VoiceOver 把整个指标作为一项朗读。
- 背景：`.black.opacity(0.94)` + `RoundedRectangle(cornerRadius: 20)`。
- 文本前景色：`.white`，保证在黑色背景上的对比度。

## 3. `ExpandedUsageView`

```swift
@MainActor
struct ExpandedUsageView: View {
    @Bindable var store: UsageStore
    let close: () -> Void
}
```

从上到下的内容流：

1. **Header** — "Codex 用量"标题 + `accountSubtitle`（脱敏邮箱 + 套餐）+ 刷新指示器 + 关闭按钮。
2. **额度区** — 渲染 `snapshot.quotaWindows`：每行含标题、剩余百分比进度条、可选的重置时间。
3. **范围选择器** — `Picker("统计范围", selection: ...)`，值来自 `UsageRange.allCases`。
4. **汇总区** — Tokens 总量 + 估算成本（成本为 `—` 时显示占位；存在未知模型时附加副标题）。
5. **每日趋势** — `DailyTrendView(days: snapshot.dailyUsage)`。
6. **常用模型** — `ForEach(snapshot.topModels)`，百分比用 `NumberFormatter.percent.precision(.fractionLength(0))`。
7. **警告** — 仅展示 `visibleWarnings.first`，避免多行堆叠。

设计要点：

- 每个区块都使用 `fixedSize(horizontal: false, vertical: true)` + `layoutPriority` 控制压缩顺序：警告 > 趋势 > 头部/额度 > 模型。
- `header` 中的关闭按钮使用 `.accessibilityLabel("收起")`。
- 顶部 32pt 透明区域确保文字/控件不会落入物理刘海遮挡区。

## 4. `DailyTrendView`

```swift
struct DailyTrendView: View {
    let days: [DailyUsage]
    @State private var selectedIndex: Int?
}
```

- `maximum = max(days.map(\.tokens.total).max() ?? 0, 1)`：全零时仍占满区域，使悬停仍可选择。
- `HStack` 中按列等宽铺 `days.count` 根 `Capsule`，高度按 `day.tokens.total / maximum` 比例缩放。
- `onContinuousHover` 把鼠标 x 坐标通过 `DailyTrendSelection.index(for:width:count:)` 映射为列索引；越界被 `min/max` 收敛到首尾。
- 选中的柱添加 `Capsule().stroke(.white.opacity(0.8), lineWidth: 1)` 描边，并在图表上方叠加 `tooltip`。
- `costText(for:)` 包含 "（未含 N 个未知模型）" 后缀。

`DailyTrendSelection` 是纯函数，便于单元测试：

```swift
enum DailyTrendSelection {
    static func index(for locationX: CGFloat, width: CGFloat, count: Int) -> Int?
}
```

## 5. 视图与状态层的边界

- 视图只读取 `store.snapshot`、`store.isRefreshing` 与 `store.snapshot.selectedRange`。
- 视图通过 `store.selectRange(_:)` 改变范围选择 — 这是视图对状态层的唯一写操作。
- 关闭面板、切换三态等"展示态"操作通过 `presentation` Binding 回写 `NotchPanelController`。
- 视图不持有任何文件路径、进程或缓存 URL。
