# Codex 刘海面板交互与视觉修复设计

- 日期：2026-07-23
- 状态：用户已确认，待审阅本文档
- 范围：仅修复刘海悬停稳定性、展开面板视觉层级、趋势提示和成本估算口径。

## 1. 目标与边界

将现有面板恢复为紧凑的动态岛式单屏体验：数据不会落在物理刘海覆盖区，悬停不会闪烁，完整面板没有纵向滚动条，模型列表可完整看到。

保持既有边界：只读取 Codex CLI RPC 与本地会话日志；不读取浏览器 Cookie、不嵌入 WebView、不假设或换算订阅额度的绝对 Token 上限。

## 2. 视觉与布局

### 2.1 统一锚点

- 所有状态都以屏幕顶部中心为锚点。
- 视觉内容预留 32pt 顶部连接带，该区域仅与物理刘海融合，不放文字、数值或可读控件。
- 静默态视觉胶囊为约 150 × 30pt；悬停态为约 300 × 80pt；展开态固定为 368 × 430pt。
- 在有刘海屏幕上，内容从连接带下方开始；无刘海屏幕维持相同顶部居中形态。

### 2.2 展开态信息结构

展开态从上至下固定为：

1. 标题、脱敏账号、套餐和收起按钮。
2. 每个实际返回的额度窗口。显示“剩余 XX%”，其中 `XX = max(0, 100 - usedPercent)`；进度条同样显示剩余比例，并保留重置时间。
3. `1 天 / 7 天 / 14 天 / 30 天` 周期选择。
4. Token 与估算成本两张摘要卡。
5. 单行高度的紧凑每日趋势柱图。
6. 常用模型标题与最多四行模型占比。

展开态不使用 `ScrollView`。超过三种模型时，前三名按 Token 占比展示，剩余项合并为“其他”，共最多四行；因此模型区始终完整可见，不会被底部圆角裁切。

## 3. 交互设计

### 3.1 悬停状态机

- 面板窗口的命中区域在静默与悬停状态之间保持稳定，不因视觉尺寸变化使光标离开窗口。
- 鼠标进入后延迟 120ms 打开预览；鼠标真正离开稳定命中区域后延迟 250ms 收起。
- 点击预览进入展开态；展开态点击外部或按 `Esc` 收起。
- 面板形变沿顶部连接带展开；系统“减少动态效果”开启时取消形变动画。

### 3.2 趋势提示

- 趋势图按所选范围绘制 1、7、14 或 30 根紧凑柱。
- 指针进入图表后，根据横坐标选中最近日期柱；该柱显示高亮描边。
- 浮层显示日期、当天 Token 和当天估算成本；若当天含未知价格模型，成本文案说明“未含 N 个未知模型”。
- 指针离开图表时移除浮层；无每日数据时显示“暂无本地用量”。

## 4. 成本数据口径

Codex 本地日志提供模型与 Token 分类，但价格表可能没有某个模型（例如 `codex-auto-review`）。当前实现将任一未知模型视为整个日期无法估算，导致总成本显示“—”。

修复后，成本按以下规则聚合：

- 有价格模型：按内置价格表正常计算，并累加为部分估算成本。
- 未知价格模型：不计入金额，但记录模型名称和数量。
- 摘要卡与趋势浮层显示已知模型的部分估算成本，并明确标注“未含 N 个未知模型”。
- 若该范围内没有任何已知价格模型，才显示“—”。
- 已有“模型 X 暂无价格，成本未计入”警告继续保留。

这保证显示的金额始终可追溯，且不会把部分估算伪装为完整账单。

## 5. 组件与数据流

- `NotchPanelController`：持有稳定命中窗口、计算视觉容器位置，并管理点击外部和键盘收起。
- `NotchRootView`：只管理三态转换与悬停延迟；视觉尺寸变化不能改变命中区域。
- `PeekUsageView`：保留两项核心指标；额度指标改为“剩余百分比”。
- `ExpandedUsageView`：负责固定单屏布局、趋势柱图和悬停提示，不持有数据源。
- `SessionUsageRepository.aggregate`：产生每日成本及未知价格模型计数；`UsageStore` 汇总范围成本和警告。

不引入第三方依赖、网络请求或新的持久化结构。

## 6. 错误与降级

- 没有额度窗口时，隐藏额度区；预览继续显示今日 Token 与估算成本。
- 没有本地日志时，趋势区显示空状态，摘要 Token 为零。
- 所有模型都未知价格时，成本保持“—”并展示既有价格警告。
- 成本仅为部分估算时，数值与“未含 N 个未知模型”同时显示，不能只显示数值。

## 7. 验收与测试

### 自动化

1. 剩余百分比对 0%、42%、100% 的已用比例分别为 100%、58%、0%。
2. 已知与未知模型混合时，成本等于已知模型之和，并记录未知模型数量；全部未知时成本为 `nil`。
3. 各统计周期均最多输出四个模型行（前三名和“其他”），且占比总和正确。
4. 趋势选择逻辑将边界横坐标映射到首、末日期柱。
5. 屏幕定位测试覆盖连接带偏移和稳定命中尺寸。

### 图形验收

1. 光标停在刘海和预览内 10 秒，预览不反复开关。
2. 预览与展开态的任何数据均不被物理刘海遮挡。
3. 展开态无滚动条，常用模型前三名和“其他”完整可见。
4. 1、7、14、30 天趋势都能显示指定日期的 Tooltip。
5. 含 `codex-auto-review` 的实际日志仍显示部分估算成本及未计入提示。

## 8. 非目标

- 不接入 ChatGPT 网页设置页或 CodexBar 的 WebView/Cookie 机制。
- 不把周额度百分比伪换算为 Token 数。
- 不添加模型价格的在线同步或远程配置。
