# Token 用量中文单位设计

- 日期：2026-07-28
- 状态：用户已确认，待审阅本文档
- 范围：仅调整 Token 数量的百万级与亿级显示单位。

## 1. 目标与边界

将原有英文 `M` 显示替换为中文“万”，并在数值达到 1 亿时才切换为“亿”。不调整千级及以下的 `K` 显示，也不改变 Token 聚合、价格估算或 UI 布局。

## 2. 格式化规则

- `1,000,000` 至 `99,999,999`：以“万”为单位，保留 0 位小数。例如 `12,300,000` 显示为 `1230万`。
- 小于 `100,000,000` 的值始终不显示“亿”。例如 `99,999,999` 显示为 `10000万`。
- `100,000,000` 及以上：以“亿”为单位，保留 1 位小数。例如 `100,000,000` 显示为 `1.0亿`。
- 小于 `1,000,000`：沿用现有整数值 / `K` 格式。

## 3. 实现与测试

- 仅修改 `UsageFormat.tokens(_:)` 的单位分支与中文注释。
- 将 `UsageFormatTests` 改为覆盖“万”显示、1 亿切换边界和亿级显示。
- 不新增依赖、配置或格式化抽象，所有既有 UI 自动复用同一格式化结果。
